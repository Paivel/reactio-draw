Reactio Draw — local API (Mac, Windows and Linux apps)

While Reactio Draw is open, scripts on the same computer can send it commands over HTTP.
The API is off until you turn it on: Info tab (right panel) → Local API. The choice is remembered; turn it
off there again and nothing listens.
It listens on 127.0.0.1 only (not reachable from other computers), and every request needs a token.
It answers scripts on this computer only: requests a web browser sends for a page (they carry an Origin
header) are refused, and the address must be 127.0.0.1 or localhost with the port from api.json.

Where to find the port and token (the file exists only while the app runs):
  Windows: %APPDATA%\ReactioDraw\api.json
  Mac:     ~/Library/Application Support/ReactioDraw/api.json
  Linux:   ~/.config/ReactioDraw/api.json
It contains {"url": "http://127.0.0.1:47615/api", "token": "...", "port": 47615}.

Request: POST <url>, header X-Reactio-Token: <token>, JSON body {"op": "<command>", "args": {...}}
Answer:  {"ok": true, "result": ...}  or  {"ok": false, "error": "..."}

Commands (help {"op": "<command>"} gives every argument; an argument a command does not take is an error)

Basics
  help            {"op": "addScheme"}                  a command's arguments; help alone lists the commands;
                                                       {"op": "guide"}: how to copy a figure, step by step
  version                                              the name and version of Reactio Draw
  undo, redo                                           every command is one undo step; the answer says what was undone
  batch           {"ops": [{"op": "move", "args": {...}}, {"op": "delete", "id": 12}], "stopOnError": false}
                                                       several commands as one undo step (arguments in "args" or beside
                                                       "op"); answers the errors, the ids made and each command's answer
                                                       in "results" (pictures left out; "results": false for none);
                                                       through the MCP, {"path": "ops.json"} reads the ops from a file
                                                       A command from outside that runs for more than a second shows a
                                                       bar over the sheet (the command, its step, the time) with Stop: a
                                                       batch stops between its commands, fitToReference between its
                                                       structures, and says so ("stopped"); what was done stays.
                                                       Through the MCP: {"op": "result", "args": {"cancel": true}} stops
                                                       waiting for a long command.
  saved, markSaved                                     unsaved changes? / mark the drawing as saved
  readOnly        {"on": true}                         view only (toolbars hidden, nothing can be changed)
  zoom            {"value": 1.5} or {"fit": true}      zoom (1 = 100 %) or fit the drawing in the window

Documents
  newDocument     {"name": "Compare"}                  a new empty document in its own tab, shown at once
  documents                                            the open documents and which one is shown
  openDocument    {"id": "…"} or {"name": "…"}         show another one; the commands work on the document shown
  closeDocument   {"id": "…"} or {"name": "…"}         close one without asking (none given: the one shown);
                                                       newDocument gives an error when no tab more fits
  set             {"text": "...", "format": "mol"}     replace the whole sheet (format found from the text if left out)
  import          {"text": "...", "format": "cdxml"}   add a file's content to the sheet
  export          {"format": "smiles|mol|sdf|rxn|cdxml|xyz|sdf3d|svg|json"}   the drawing as a file text; xyz: 3D for
                                                       quantum chemistry (hydrogens added, lowest MMFF94s+ conformer;
                                                       maxConformers 20, maxSeconds 30); sdf3d: the same 3D shape as
                                                       an SDF with its bonds, charges and configuration
  clear           {"keepReference": true}              empty the sheet (keepReference: the figure laid last stays)
                  {"resetIds": true}                   … and the ids start again at 1 (a figure kept becomes 1)

Reading the sheet
  list                                                 the structures: index, id, SMILES (stereo as drawn), formula, MW, role, box
  objects         {"type": "text", "ids": [...], "fields": ["id", "box"]}   every object (structures, arrows, + signs,
                                                       texts, shapes, pictures, charts) with type, id and box
                                                       ("image" or "picture" for pictures)
  atoms           {"index": 0, "fields": ["n", "x", "y"]}   the atoms of a structure numbered from 1 as made (as written
                                                       in the SMILES or Molfile), with x, y and their bonds (to, order, style)
  properties      {"index": 0}                         formula, masses, elemental analysis and more
  scheme, table                                        the reaction scheme in order; the reagent table
  selection, select {"index": 0} / {"all": true} / {}  what is selected; select structures, all, or nothing
  check           {} or {"layout": true}               valence errors, unreadable labels and structure checks
                                                       ("shortStereo": a wedge or hash whose visible part is
                                                       under 10 units, which reads as a wedge; "stereoProblems": a
                                                       wedge or hash with its wide end at the stereocentre, on an atom
                                                       that is no stereocentre, two in a chain, two of one kind at a
                                                       centre with three bonds — setBond answers them too;
                                                       "tightAngles": open-chain atoms whose bonds stand under 55°
                                                       apart, an acetyl folded onto itself); layout skips an
                                                       orbital on its own atom and a line or arc tied to atoms
                                                       (overlaps of a structure are measured by its bonds and letters,
                                                       not its box; problems[].other: {n, element, issue, level}; level err, warn or
                                                       hint; ok is false only for errors and warnings); layout: true
                                                       gives the overlaps of structures, arrows and texts (not the
                                                       figure, orbitals on their atom or curved arrows at atoms;
                                                       "ignore": [ids])
  picture         {"scale": 1, "region": [x0, y0, x1, y1]}   a PNG (base64) of the sheet, or of a part: region, or
                                                       round some objects ("ids") or structures ("index": [0, 2])

Coordinates: sheet units (1 = a screen pixel at 100 %), x right, y down, a bond about 40. A structure's x, y is the
centre of its box; addText's x, y is the start of the first line's baseline. Every SMILES in the answers carries the
drawn stereochemistry: @/@@ from wedges and hashes, / and \ for E/Z.

Through the MCP bridge (Claude): import/set/addImage/addScheme take {"path": "…"} to read a file, export/picture
{"path": "…"} write one, and any command's answer goes to a file with {"out": "…"}. A command still running after
25 s answers "still working"; {"op": "result"} fetches its answer.

For one-off jobs without the app open (pictures, conversion, checks), use the command line: "Command line.txt".

Example (Python 3, no extra packages):

  import json, os, pathlib, urllib.request
  p = pathlib.Path(os.environ["APPDATA"]) / "ReactioDraw" / "api.json"            # Windows
  # p = pathlib.Path.home() / "Library/Application Support/ReactioDraw/api.json"  # Mac
  # p = pathlib.Path.home() / ".config/ReactioDraw/api.json"                     # Linux
  info = json.loads(p.read_text())
  def rd(op, **args):
      req = urllib.request.Request(info["url"], json.dumps({"op": op, "args": args}).encode(),
                                   {"X-Reactio-Token": info["token"], "Content-Type": "application/json"})
      return json.load(urllib.request.urlopen(req))

  print(rd("calc", smiles="CC(=O)Oc1ccccc1C(=O)O"))   # aspirin: C9H8O4, 180.159 ...
  print(rd("addName", name="(2S)-2-aminopropanoic acid"))
  print(rd("name", index=0))
